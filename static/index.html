本站是一个非官方的《最终幻想 14（FFXIV）》国服历史招募板归档与搜索工具，用于检索过去的野队招募信息。

本项目的代码结构、业务逻辑实现、前端 UI 样式、部署脚本等，大量使用了 AI 编程辅助（大语言模型自动生成 + 人工修改验证）来完成。开发者对功能、数据流、筛选规则、数据库结构做了业务级别的设计与验收，但代码中可能残留 AI 生成的冗余或存在未覆盖的边界情况。

如发现 Bug 或功能问题，欢迎在 GitHub 仓库中提交 Issue。

  • 招募数据来源（实时 API）： xivpf.littlenightmare.top/api/listings （感谢上游作者提供公开 API）
  • 参考 UI/功能组织： xivpf.ff14.xin
  • 本项目源码（欢迎 Star / Issue / PR）： github.com/Bqiying/FFRecruit

📅 数据采集说明

  • 数据起始时间：2026 年 8 月 14 日。此日期之前的招募历史本站未留存，无法查询。
  • 采集周期：爬虫默认每 60 秒从上游 API 拉取一次全量招募。
  • 可能漏记的情况：招募在游戏内存活时间短于一轮采集周期（约 1～2 分钟）时， 有一定概率不会被本站记录到，属于正常现象，无法通过重新抓取恢复。
  • 招募关闭判定：同一轮拉取中未再出现的招募将被自动标记为「已关闭」；同时按「同一个角色同一时间只能有 1 个招募进行中」做了兜底。
